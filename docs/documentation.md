# TODO-list

Проект управления задачами

Этот проект представляет собой приложение для списка задач (todo list), использующее Docker для контейнеризации, PostgreSQL для базы данных, а также Go для backend-разработки. Проект использует Docker Compose для управления контейнерами, включая контейнеры для базы данных, миграций и приложения.

## Требования

Для запуска проекта необходимы следующие зависимости:

- **Docker** — для создания и управления контейнерами.
- **Docker Compose** — для управления многоконтейнерными приложениями.

## Настройка окружения

Проект использует переменные окружения, которые задаются через файл `.env`. Эти переменные используются для конфигурации подключения к базе данных и других настроек.

### Переменные окружения

- **POSTGRESQL_URL** — строка подключения к базе данных PostgreSQL, включает имя пользователя, пароль, хост, порт и имя базы данных. Эта переменная используется в приложении для подключения к базе данных.
- **POSTGRES_USER** — имя пользователя для подключения к базе данных PostgreSQL.
- **POSTGRES_PASSWORD** — пароль пользователя для подключения к базе данных PostgreSQL.
- **POSTGRES_DB** — имя базы данных, которая будет использоваться в проекте.

### Пример `.env` файла

```env
POSTGRESQL_URL=postgres://postgres:1703@postgres:5432/todo_list?sslmode=disable
POSTGRES_USER=postgres
POSTGRES_PASSWORD=1703
POSTGRES_DB=todo_list
